## AUTO-DIG NOW KEEPS USER AUTHORITY ATTACHED TO THE RUN

## Changes

Quasar's local Auto-Dig control plane now carries the authenticated principal through live WebSocket dispatch instead of dropping it at the actor boundary.

Delegated user sessions and internal worker sessions are tagged separately. Runs created by one delegated principal stay isolated from another principal even inside the same workspace.

That gets the local Auto-Dig path closer to StarIntel's shared actor-control semantics: durable run lifecycle underneath, trusted actor dispatch in the middle, user authority preserved end to end.
