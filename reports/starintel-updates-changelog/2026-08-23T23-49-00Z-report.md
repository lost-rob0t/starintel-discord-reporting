# CLIENTS CAN FINALLY ASK STAR SERVER WHAT IT ACTUALLY SUPPORTS

## Changes

- Star Server now exposes public `GET /api/v1/capabilities`, so clients can discover supported features instead of guessing from 404s or hard-coding route assumptions.
- The response reports API/document revisions, HTTP transport, configured auth mode, request/bulk limits, current feature availability, and the existing legacy document/search/target routes.
- It also says what is **not** there yet: target leases, streams, and OpenAPI are explicitly advertised unavailable on the landed server build.
- The endpoint has contract tests for the stable envelope, route inventory, public discovery behavior, and non-disclosure of configured secret material.
