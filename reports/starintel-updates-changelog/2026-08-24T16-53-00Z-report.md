# STAR SERVER JUST GOT A PUBLIC READ PLANE WITHOUT MAKING THE CONTROL PLANE PUBLIC

## Changes

`GET /api/v1/search` and `GET /api/v1/stats` can now run anonymously when public mode is enabled. Search still goes through server-owned authorization and bounded dataset scope, while stats stay aggregate-only.

The split is explicit: public read endpoints can be open, but ingest, targets, deletes, admin, credentials, and leases stay authenticated. Private mode keeps search and stats mounted but puts auth back in front of them.

Capabilities now report the effective public-mode authority so clients do not have to guess what the server allows.
