## PROLOG-RLM DURABLE CONTEXT MOUNTS NOW SURVIVE RECOVERY RACES

## Changes

Durable context mounts now keep persistent cache entries isolated by artifact store and correctly rehydrate canonical persisted mount sources.

Mount publication also binds the artifact value before projection, and concurrent recovery is now race-safe instead of letting competing recovery paths corrupt the durable mount state.
