# Zara moves Prolog resolution onto IntentFrame

## Changes

Zara's Prolog command resolver now targets the typed `IntentFrame` contract instead of leaving command meaning split across looser intent forms.

The landed slice adds a canonical semantic corpus for realistic utterances and clarification follow-ups, carries frame status and slot origin through resolution, and adds screenshot as a built-in intent. The corpus also pins boundary and known-defect cases so later resolver changes have something concrete to flip instead of silently changing semantics.
