# AGENT ZERO CAN NOW HAND ITS CONTEXT AND TOOLS TO PROLOG-RLM WITHOUT DUMPING THE WHOLE WORLD INTO THE MODEL

## Changes

Prolog-RLM now has an Agent Zero adaptation boundary for DOX/project instructions, skills, tool metadata, and bounded context units. Prolog owns normalization, selection, context packing, token accounting, and fingerprints while executable handlers stay trusted host code.

The same integration wires external tool packs through the normal Prolog-RLM schema, capability, authority, effect, scheduling, and trace boundaries instead of giving plugins an alternate execution lane.

The adapter was then isolated under the adaptor tree and its closed-data handling hardened so nested anonymous dicts canonicalize deterministically while real variables and cycles fail closed.

>Agent Zero brings the pile
>Prolog decides what actually enters context
>tools still cross authority checks
>context engineering becomes runtime policy
