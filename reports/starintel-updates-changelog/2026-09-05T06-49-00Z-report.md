## 🗣️ Zara: desktop and command execution now stay on the daemon

**Status:** `LANDED` • `master`

## Changes

- Desktop sessions now use the persistent Zara daemon/client path by default instead of spinning up isolated assistant state.
- One-shot commands such as timers follow that same daemon route, keeping state and execution behavior consistent.
- Parameterized user commands now compile and resolve their slots at runtime.
- Unknown or unconfigured application launches now fail closed instead of falling back to an arbitrary executable.
