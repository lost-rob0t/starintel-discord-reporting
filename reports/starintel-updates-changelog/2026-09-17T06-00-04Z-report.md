# Tek9: star-git gets an immutable archive core

## Changes
- Immutable revision history now has deterministic LZMA archive packs.
- Tree snapshots and explicit ref restoration sit alongside commit provenance and a CouchDB revision index.
- Hot-payload eviction defaults to requiring a verified remote-custody receipt. History metadata, refs, and indexes stay hot; pinned objects are not evicted.
- Availability lookup and restore planning distinguish hot objects, local packs, verified remote packs, and missing data.

The custody API records evidence supplied by a trusted caller. It does not upload to a provider or perform remote readback itself. This is the archive storage core, not a completed automatic object-storage pipeline.
