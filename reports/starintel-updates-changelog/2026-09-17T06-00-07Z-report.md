# Zara Plugins: remote failures without remote error leakage

## Changes
- The Agent Zero integration sanitizes remote error details before surfacing a failure.
- Remote exception causes are suppressed as well, closing the traceback-reflection path rather than only cleaning the top-level message.

Failures still surface. The change is that remote exception detail no longer gets copied straight through as the user-facing diagnostic.
