## PROLOG-RLM MOVES THE TYPED-PLAN CONTRACT INTO THE RUNTIME

## Changes

The root planner's typed JSON contract now lives in the core RLM skill path instead of benchmark-only prompt glue. The benchmark no longer owns the grammar it is supposed to measure.

Planner-only context is also kept at the planner boundary. Executed model steps now produce task output without inheriting planner instructions, so a valid plan cannot accidentally become the final answer.

The fix keeps recursive capability checks and the closed typed-plan interpreter intact while adding a deterministic final-handoff regression.
