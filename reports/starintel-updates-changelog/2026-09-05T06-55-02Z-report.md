## 🧩 Zara Plugins: StarIntel Server is now exposed as a Zara tool surface

**Status:** `LANDED` • `main`

## Changes

- A dedicated StarIntel Server plugin now exposes the server API through Zara tools.
- Configuration keeps credentials out of ordinary tool output, while the client supports bounded HTTP requests plus OAuth/form/text request bodies.
- Plugin discovery and registry metadata are included, so the integration can be installed and resolved like the rest of Zara's extension surface.
