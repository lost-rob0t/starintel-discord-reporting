# Prolog-RLM makes `context_peek` match the schema it advertises

## Changes

- `context_peek` now derives its projected selector schema and native validation from the same contract instead of letting them drift apart.
- Optional `index` and `count` fields now enforce the advertised bounds when present. Head/tail keep a bounded default count, item keeps its default index, and unknown fields or selector types still fail closed.
- The landed regression coverage includes the Auto-Dig-shaped `{count:20,index:0,type:"head"}` call plus omitted-count defaults and schema/validator boundary checks.
