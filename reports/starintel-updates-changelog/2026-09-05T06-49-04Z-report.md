## 🧭 Task Steward: development is now governed as an expert system

**Status:** `LANDED`

## Changes

- Task Steward now acts as the development-control expert system: it reasons over repository state, work queues, worker roles, and review evidence to decide what should happen next.
- Repository evidence is reconciled against actual development state instead of trusting worker self-reporting alone.
- Implementation, RAGE, and reviewer responsibilities are represented as distinct capabilities, keeping verification separate from the worker that produced the change.
- The operating model favors persistent, coherent work queues over one-prompt, one-task development.
