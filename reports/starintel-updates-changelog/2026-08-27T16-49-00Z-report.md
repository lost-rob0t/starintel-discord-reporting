## AUTO-DIG NOW SURFACES RLM FAILURES WITHOUT LEAKING RAW DIAGNOSTICS

## Changes

Auto-Dig's supervised Prolog actor now runs the native RLM path with a 50k token ceiling instead of the old 8,192-token cap that could fail during normal planner retries.

RLM and MCP diagnostics are scrubbed at the emission boundary before live Actions logs or persisted artifacts see them. Failed research runs now emit a bounded sanitized failure report back to the investigation workflow instead of dying with an empty stderr trail.
