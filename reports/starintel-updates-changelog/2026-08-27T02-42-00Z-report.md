## PROLOG-RLM NOW CATCHES TOOL-CHOICE MISMATCHES BEFORE DISPATCH

## Changes

Provider/model profiles can now declare which `tool_choice` modes they actually support, and Prolog-RLM normalizes that compatibility before streaming or normal HTTP dispatch.

An auto-only profile can turn a plain `required` request into `auto`. A specific-function request that the profile cannot support fails explicitly instead of being silently weakened.

Malformed compatibility config also dies before credential resolution or network effects. This is compatibility policy, not extra tool authority.
