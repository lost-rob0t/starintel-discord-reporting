# Prolog-RLM stops advertising context access it did not grant

## Changes

- Direct mode now mentions the initial context alias only when the session actually has context operations. That stops the model from being invited to read context that fail-closed capability checks will reject.
- The pinned live lane now gives mandatory-reasoning models enough token headroom for CLI and streaming checks instead of letting reasoning consume the entire response budget.
- The paid cache acceptance test now uses the configured pinned paid model instead of requiring the old 120B pin, while still demanding a real majority of warm-turn cache hits.
