# Zara adds typed capability and provider execution plans

## Changes

Zara can now resolve complete intent frames into typed `ExecutionPlan` candidates using a declarative Prolog capability/provider knowledge base instead of jumping straight from intent to concrete execution.

Provider selection carries location, side-effect class, authorization requirements, argument bindings, ambiguity handling, and stale-plan checks as data. Open frames still fail closed for clarification.
