## 🏗️ StarIntel infrastructure: self-hosted development is now the normal path

**Status:** `LANDED`

## Changes

- The self-hosted forge is now treated as the primary development source, with external hosting used as a synchronized mirror rather than the operational center.
- Repository synchronization now paces remote API work and isolates failures so one bad repository does not stall the wider sync loop.
- Webhook reconciliation moved out of the deployment-critical path into periodic drift repair, avoiding deployment rollbacks caused by slow enumeration.
- CI runner capacity was increased to support the growing autonomous-worker load.
