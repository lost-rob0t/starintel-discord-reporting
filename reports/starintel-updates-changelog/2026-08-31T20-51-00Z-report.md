# Auto-Dig gets one bounded repair pass for malformed native tool JSON

## Changes

Auto-Dig's native direct-mode harness can now recover from one specific provider failure instead of dropping the whole research slice when a tool call arrives with malformed raw JSON arguments.

The landed runner detects that normalization failure, retries once with stricter JSON guidance and a smaller budget, caps parallel native calls in the repair prompt, and lowers the normal run cost ceiling. The live workflow then pinned the validated Prolog-RLM wire fix and added the native-tool regression suite to its smoke checks.
