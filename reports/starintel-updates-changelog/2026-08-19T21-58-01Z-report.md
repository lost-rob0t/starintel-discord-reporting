# StarLang: logic calls are now compiler IR

## Changes

StarLang now has an engine-neutral logic backend layer and a final-owned logic-call IR. The compiler can validate and normalize a logic call, carry it through compilation, then materialize it for the selected backend instead of baking one logic engine into the language.

The IR also has canonical JSON output, so plans can be compared and tested deterministically.

The change landed with independent conformance/materialization tests and compiler policy tests.
