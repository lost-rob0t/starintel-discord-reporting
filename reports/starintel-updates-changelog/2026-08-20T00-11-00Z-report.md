# Auto-Dig now has a real request queue

## Changes

- Research requests can now be queued as GitHub Issues with priority, scope, seed sources and completion criteria.
- Equivalent requests get a stable fingerprint, so rerunning the queue action reuses the existing issue instead of spawning duplicates.
- The hourly Auto-Dig worker drains queued `investigation-target` issues before falling back to autonomous research.
