# Hackmode gives HTTP requests an operation-scoped typed contract

## Changes

HTTP request objects now carry explicit operation and run identity, redirect policy, timeout policy, client profile, and capture mode instead of leaving those execution choices implicit.

The landed slice validates those fields before use and emits execution provenance without request headers, bodies, URL credentials, or secrets. The executable impersonating backend/IPX integration is still separate work.
