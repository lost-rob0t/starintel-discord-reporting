# StarIntel infrastructure stopped being a pile of one-off boxes

## Changes

- The defined stack can now converge through one declarative deployment path instead of hand-wiring each host separately. Edge routing, the private tunnel, and ingest deployment are managed as one system.
- Reproducible guest bootstrap images and exact-revision build jobs landed, so deploys can be tied to a specific known build instead of whatever happened to be current at the time.
- The live deployment validator got hardened for repeated runs and transitional state. Less `worked once, ship it` energy. More actual convergence.
