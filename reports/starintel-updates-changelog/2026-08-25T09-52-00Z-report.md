# PROLOG-RLM CLI HELP STOPS FAILING LIKE A COMMAND NOW

## Changes

- `--help` is now a successful CLI dispatch path instead of falling through normal command/provider handling and returning failure.

- Global help, `rlm --help`, and supported command help scopes now return a passing help session and exit zero. Unknown commands with `--help` still stay unknown instead of being accidentally blessed as valid.

- Regression coverage was added for the global and `rlm` help paths before the fix landed.
