# starintel-server: last two weeks

## Changes

- **Target leases got real backing.** StarIntel added a backend-neutral lease/fencing protocol, then a Valkey backend with TTLs, idempotency and stale-writer protection.
- **Human accounts landed.** Persistent users, password login, first-run account setup and user-management routes are now on `master`.
- **Startup/shutdown got less fragile.** The server now owns its runtime lifecycle and readiness instead of relying on a global thread join.
- Stability work fixed CouchDB view queries, RabbitMQ queue-argument recovery, Valkey cluster behavior and corrupt lease records.

## Tests

There is **no published line-coverage percentage**, so I'm not inventing one.
