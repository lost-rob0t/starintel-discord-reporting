# Tek9 materialized views can read named databases

## Changes

Tek9 materialized views are no longer limited to the primary document database. A view can now declare a named source database, and both full rebuilds and incremental application read from that declared source.

Existing views keep the primary database as their default. Missing named sources fail closed instead of being silently created, and the source identity is exposed through the public view API.
