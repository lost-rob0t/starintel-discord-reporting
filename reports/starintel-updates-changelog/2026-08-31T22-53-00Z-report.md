# Prolog-RLM isolates malformed raw native arguments per call

## Changes

Raw malformed native arguments can now become a bounded per-call repair fault once the call envelope, ID, type, and tool name are safely attributable, instead of aborting the whole native-call batch.

The new classification path retains only wire text for the faulted entry, keeps malformed envelopes and duplicate IDs batch-fatal, and never gives the rejected call an execution path. Original-request effect isolation still applies before valid siblings can execute.

The recorded exact-head gate passed 1,138/1,138 deterministic PlUnit tests, plus 16/16 deterministic benchmark and 15/15 deep-experiment checks.
