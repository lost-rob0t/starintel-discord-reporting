## PROLOG-RLM CAN RESUME THE PARENT AFTER DELEGATED WORK

## Changes

Compiler-authenticated unresolved prompts can now go through the existing supervised subagent path and return into exactly one bounded parent continuation.

The parent capability set comes from live runtime state, not caller claims. Failed, cancelled, timed-out, budget-exhausted, or malformed child results do not get promoted into a successful resume.

Subagent task deadlines are host-bounded too. A model can request a duration, but it cannot widen the host maximum or rewrite the rest of the completion budget.
