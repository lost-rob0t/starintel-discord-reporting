## 🧠 prolog-rlm: deterministic final synthesis

**Status:** `LANDED` • `main`

## Changes

- Direct-mode deadline failures are now **typed** instead of collapsing into generic provider errors.
- The runtime reserves wall-clock time for one **tool-free final synthesis** before the hard deadline.
- Evidence acquisition can also stop by model-call count, so fast providers cannot burn the whole run on tools.
- Closing turns that still emit tool calls fail explicitly, and deadline regressions are deterministic and sleep-free.
- Verified deterministic suite: `1168/1168` on SWI-Prolog 9.0.4 and 10.0.2.
