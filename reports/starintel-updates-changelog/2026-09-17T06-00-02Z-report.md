# Quasar: package the Lisp runtime, not just the browser

## Changes
- The hosted Common Lisp runtime now has a packaged deployment path, including the saved-image server.
- The standalone web edition has a dedicated `web-dist` build output.

The distinction is deliberate: the browser edition is a subset. Canonical workspace state, durable graph operations, and runtime control still belong to the Common Lisp control plane, not a second browser backend.

This update covers the hosted and standalone-web packaging, not the separate Android application.
