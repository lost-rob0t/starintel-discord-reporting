# QUASAR CAN NOW STREAM LARGE WORKSPACES THROUGH TEK9 WITHOUT DRAGGING THE WHOLE DATASET INTO RAM

## Changes

Quasar moved its production Tek9 path to bounded direct reads for documents, workspace pages, revisions, and graph snapshots instead of rebuilding large heap-backed workspace state for read-only operations.

Browser imports now use durable staged chunks with explicit sequence numbers, restart-safe promotion, replay handling, revision-conflict protection, abort/expiry cleanup, and protocol errors for malformed or missing chunks.

The landed slice includes a real 10,000-document fixture plus adversarial coverage around restart atomicity, bounded storage, malformed import traffic, and duplicate/replayed promotion behavior.
