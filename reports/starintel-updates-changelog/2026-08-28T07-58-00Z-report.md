## AUTO-RESEARCH GETS HUMAN-GATED ADARD STAGE WORKERS

## Changes

Auto-Research now has separate workers for ADARD coordination, source enrichment, contract/version audit, approved implementation, and verification. The coordinator routes work by stage instead of treating every task as "do more research."

The authority boundary is explicit: research and design do not self-promote, implementation requires an already human-approved canonical design/contract, and verification may record conformance only from current code plus executed evidence. The source-enrichment worker also searches the existing corpus first so a new upstream tool does not automatically become duplicate research spam.

>research finds source
>audit finds delta
>human gate stays human
>implementation worker is finally not allowed to invent its own constitution
