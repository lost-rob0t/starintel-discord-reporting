# Zara routes AMD STT requests onto the Vulkan backend

## Changes

Zara now treats `amd`, `rocm`, `hip`, and `vulkan` as AMD GPU intent instead of rewriting them to NVIDIA CUDA. Local STT requests using those device tokens are routed to the packaged whisper.cpp Vulkan backend, with a visible notice when Zara switches providers.

Remote STT providers are left alone because the local device setting is inert for them. `cuda` keeps its NVIDIA meaning and existing CPU-fallback behavior.
