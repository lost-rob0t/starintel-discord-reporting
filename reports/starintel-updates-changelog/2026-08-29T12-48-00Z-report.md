# Auto-Dig drops the planner choke point

## Changes

- Auto-Dig research now runs through Prolog-RLM direct mode instead of requiring a typed plan before the model can touch research tools.
- The worker now exposes the full capability-filtered read-only research surface: 14 Brave/Fetch MCP tools plus bounded RLM context search, peek, and slice.
- The direct loop is bounded to 12 model turns, 24 tool calls, 32 context operations, and a 315,000-token budget, set to 30% of the currently routed model context window.
- The change landed after the old typed-plan path repeatedly died on invalid plan JSON before research could start. Missing tools and datasource gaps are now required in the research result for the next pass.
