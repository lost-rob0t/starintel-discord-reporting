## Project changelog: Zara, Prolog-RLM, Hackmode, StarIntel

- **Zara:** provider output can now stream through the agent/runtime path instead of waiting for the whole response, with cancellation-safe text events and sentence chunking. OpenRouter support was also fixed in the agent model factory, and the packaged `zara-server` entrypoint no longer trips over duplicate `PrincipalContext` class identities. <https://github.com/lost-rob0t/zara/commit/1ff26122e32baba1446f6a07461a668412db6afc> <https://github.com/lost-rob0t/zara/commit/de7c91c80a1380781ef41d0b6a85d0f1725d812a>

- **Prolog-RLM:** native direct mode now isolates recoverable preflight faults per tool call, so one malformed read-only call can be returned to the model for repair without discarding valid siblings. The `context_peek` selector schema and native validator were also unified around one contract. <https://github.com/lost-rob0t/prolog-rlm/commit/6957c30c88f9548137a8ff9c3a0720f9bdadb210> <https://github.com/lost-rob0t/prolog-rlm/commit/b8206c728549f4128e8b18f0611d2d0456dc5b2d>

- **Hackmode:** the database side is getting stricter typed boundaries for operational, long-term, and global KB reads, plus bounded redacted HTTP-header evidence and canonical visual-evidence persistence. Hackpert's direct/expert-loop state accessors were hardened against caller mutation too. <https://github.com/lost-rob0t/hackmode/commit/7ca45628dbd5536b5f5e93bfac5dca170f37ef93> <https://github.com/lost-rob0t/hackmode/commit/9179e059e2582570805992a60090e0b9b8e5b638> <https://github.com/lost-rob0t/hackmode/commit/a795ecb08ac2e30363f9538fbc1a1008a93faf25>

- **StarIntel:** the duplicated autonomous StarIntel worker profiles in Auto-Research were retired after the worker migration to Hackmode, reducing two competing worker-control paths to one source of truth. <https://github.com/lost-rob0t/starintel-auto-research/commit/c3e5d568d9321d2dd859fc3e00fcf7a1bb2f7715>
