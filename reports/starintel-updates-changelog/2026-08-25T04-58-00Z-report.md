# Auto-Dig harvests stopped living in issue-comment limbo

## Changes

- Auto-Dig now has a repository-native **harvest manifest** path that materializes validated harvest packets into the canonical `digs/` corpus.
- The first landed use moved mature Worldcoin control, AMPC, and WLD evidence out of request staging and into typed StarIntel documents.
- The workflow only commits generated packet changes when the materialized output actually differs, so reruns do not manufacture duplicate data commits.
