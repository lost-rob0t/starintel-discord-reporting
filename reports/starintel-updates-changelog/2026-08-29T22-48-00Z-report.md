# Auto-Research pins StarIntel's adapter extraction seam

## Changes

Auto-Research landed the next StarIntel library-boundary slice: concrete HTTP, CouchDB, RabbitMQ, Valkey, and scheduler effects move behind narrow runtime-owned typed ports one vertical operation at a time instead of through a big-bang package rewrite.

The design keeps `star.runtime` as lifecycle/composition authority, preserves the existing lease-store protocol, and makes fake-backed application tests prove they can run without loading concrete CouchDB, broker, HTTP, or timer machinery for the operation under test.

This is **design-ready for operator review only**. Architecture approval and implementation authorization are still pending. The proposed first slice is a read-only repository vertical with a fake port, concrete CouchDB conformance, and HTTP projection after the prerequisite runtime/port boundary exists.
