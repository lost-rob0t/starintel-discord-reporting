## ⚙️ A0-Symbolics: longer symbolic/tool loops stop failing silently

**Status:** `LANDED` • `main`

## Changes

- Agent Zero now talks to Prolog-RLM through a real harness/client seam instead of an ad hoc integration path.
- The harness client is async, keeping symbolic turns from blocking the chat-loop event loop.
- Tool-only continuation turns now recover a usable query instead of falling into empty-query retry loops.
- Native Responses text/XML tool calls and malformed-but-recoverable JSON tool requests are translated back into executable tool actions instead of being dumped into chat.
