# Hackmode supervises operation-scoped HTTP capture

## Changes

Hackmode now owns the lifecycle of its operation-scoped `mitmdump` capture provider instead of treating capture as a loose side process.

The landed slice adds explicit start/stop handling, bounded restart behavior, typed lifecycle state, and regression coverage for clean shutdown versus restart exhaustion. The IPX path also records lossless HTTP evidence as an operation requirement, so passive capture has a real lifecycle boundary instead of just existing beside the operation.
