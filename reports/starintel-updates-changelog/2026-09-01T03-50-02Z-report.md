# Zara adds server-side plan execution and a toggleable autonomous mode

## Changes

Zara's server runtime can now resolve typed execution plans into versioned `api_service` providers for server-safe capabilities such as search, timers, and admin actions. Semantic, server-provider, and device-provider Prolog configuration are split so headless server boot does not import desktop command mappings.

Zara also ships a first-party `agent-mode` service plugin, disabled by default, that can schedule recurring turns, ask proactive questions, and speak through the configured TTS path. Those turns stay inside the existing `RuntimeHost`, tool, memory, and approval lifecycle instead of creating a second agent runtime or microphone loop.
