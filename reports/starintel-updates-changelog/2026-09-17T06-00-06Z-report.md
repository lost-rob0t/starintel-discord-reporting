# A0-Symbolics: updates stay on the Symbolics track

## Changes
- Self-update now follows the Symbolics distribution and its release identity. Raw upstream and unmarked targets are rejected instead of silently replacing the fork.
- Upstream synchronization has an immutable base, isolated replay worktrees, resumable conflict handling, and verification reports. Prompt overrides move into an overlay rather than edits to upstream prompt files.
- Boot restores the required symbolic plugins when stale persisted toggles would leave them disabled.
- A provider failure caused by forced tool choice can retry once without that setting, including failures after streaming has begun. It is bounded recovery, not an endless retry loop.

The upstream-replay machinery has landed; this does not announce that every prepared upstream version is already the installed release.
