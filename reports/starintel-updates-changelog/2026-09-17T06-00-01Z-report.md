# StarIntel Server: search audit events and opt-in telemetry

## Changes
- Authorized search entry points now emit query-audit events. Hosted telemetry can be loaded through an explicit deployment opt-in; export remains off by default.
- Reinstalling the observability transport is idempotent instead of duplicating setup.
- Terminal bulk jobs release their retained request payloads.

These are landed server changes. They do not imply telemetry has been enabled on every deployment or that a large-scale capacity target has been measured.
