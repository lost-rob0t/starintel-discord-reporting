## AUTO-DIG RUNS HAVE AN ACTUAL LIFECYCLE NOW

## Changes

Quasar can now start, inspect, list, pause, resume, and stop Auto-Dig runs through one durable control-plane contract. Run state survives process restarts instead of living in a disposable worker process.

Worker crashes are handled too. Active runs use bounded leases, expired work can be reclaimed, and stale workers are fenced out so an old process cannot overwrite a newer claim or a user pause/stop.

The public run view stays separate from worker lease internals, and repeated request IDs are idempotent instead of silently creating duplicate runs.
