# Star Server can finally tell clients what it actually supports

## Changes

- Star Server now exposes a public `GET /api/v1/capabilities` discovery endpoint. Clients can inspect the running service version, StarIntel document schema revision, auth mode, supported features, request limits, and the currently advertised HTTP routes instead of hardcoding assumptions.
- The response distinguishes the new versioned discovery route from legacy routes and explicitly reports capabilities that are not implemented yet, including target leases, streams, and OpenAPI.
- Regression coverage checks the stable envelope, advertised feature flags, legacy-route markers, public accessibility, auth-mode reporting, and that secrets do not leak into the discovery document.
