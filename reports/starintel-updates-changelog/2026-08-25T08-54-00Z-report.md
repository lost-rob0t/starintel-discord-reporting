# PROLOG-RLM BUDGET FAILURES KEEP THE RECEIPTS NOW

## Changes

- Completion failures for model-call, token, and cost budget overruns now carry the full observed usage object instead of only `used` and `limit`.

- That means a rejected completion still reports model calls, prompt/completion/total tokens, cost, and whether token/cost accounting was actually known.

- Regression coverage now checks those usage fields on token- and cost-budget failures, so budget rejection no longer throws away the accounting evidence that explains it.
