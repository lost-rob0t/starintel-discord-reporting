# STARINTEL OAUTH IS PUBLIC WITHOUT MAKING THE WHOLE SERVICE PUBLIC

## Changes

The new OAuth provider now has a deliberately narrow public-ingress boundary.

Only the explicitly approved authentication surface is exposed through public ingress. The rest of the service does not get dragged onto the public edge just because OAuth needs to be reachable.

The same restriction is enforced across the supported edge configurations, so this is a deployment contract instead of a one-host exception.
