# Prolog-RLM keeps tool-result correlation provider-safe

## Changes

Prolog-RLM now correlates tool-result messages by `tool_call_id` without depending on the optional tool `name` field on the provider wire format.

Internal validation still checks tool identity through the observation payload, including a dedicated regression for name mismatches.
