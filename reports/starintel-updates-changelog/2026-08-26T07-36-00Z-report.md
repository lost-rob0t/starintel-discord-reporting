## PROLOG-RLM STOPPED SHOWING THE ROOT PLANNER EVERY TOOL

## Changes

The root planner's tool list is now compiled from the prompt compiler instead of dumping every registered tool schema into context.

Capabilities still fence what can execute. The new part is earlier: the planner only sees the active tool projection selected for the current query and policy, with an explicit trusted `all_tools` mode when that is actually wanted.

Less irrelevant tool junk in context, same runtime authority boundary.
