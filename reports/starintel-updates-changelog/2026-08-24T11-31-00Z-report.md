# STAR SERVER JUST LANDED REAL OAUTH AUTHORITY

## Changes

Star Server now has a landed OAuth authorization-code authority instead of making every client live forever on legacy API keys.

The new path adds registered OAuth clients, short-lived authorization codes, access-token issuance and revocation, PKCE S256 verification, scope checks, and bearer authentication that feeds the same request security-context boundary as existing credentials.

Authorization codes are single-use and expiry-checked. Access tokens carry owner, principal type, scopes, expiry, and revocation state.

>oauth finally becomes server authority
>not "paste api key into another box"
