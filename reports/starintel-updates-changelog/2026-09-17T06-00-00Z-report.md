# Prolog-RLM: project knowledge that survives a restart

## Changes
- Tree-sitter captures now become project definitions, references, calls, imports, and exports with source and extraction provenance. Standard adapters cover Python, JavaScript, and Common Lisp; hosts can register additional adapters.
- Symbol lookup distinguishes current, stale, missing, unresolved, and ambiguous knowledge. An index with missing files no longer gets to call itself complete.
- Semantic publications are journaled atomically, rehydrated on reads, and isolated between projects. Restarting cannot promote superseded facts back into current knowledge.

This is the landed semantic-project-knowledge layer, not an announcement that every language has a built-in adapter.
