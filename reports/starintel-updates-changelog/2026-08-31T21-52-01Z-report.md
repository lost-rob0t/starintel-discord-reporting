# Hackmode wires capture into a versioned lossless spool

## Changes

Hackmode's operation-scoped HTTP capture now writes through a versioned mitmproxy addon instead of stopping at process supervision.

The landed slice adds the spool addon, wires the capture service to it, exposes the operation spool path through the typed API, and keeps captured evidence in an append-oriented handoff for later ingestion.
