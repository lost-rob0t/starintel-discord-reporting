## INFRA DEPLOYS GOT LESS CURSED

## Changes

Fresh VM provisioning is more reliable now. A boot-time failure in the deployment path was fixed, including the overlapping image/mount case that could leave a new machine dead on arrival.

Deployment authentication also stopped depending on the wrong secret-loading assumption, and DNS management now uses the supported auth path instead of failing during normal automation.

This is boring infra work in the good way: fewer half-created machines, fewer auth surprises, less manual cleanup after a deploy.
