# Hackmode adds a durable ingest-state materialized view

## Changes

Hackmode now materializes canonical outbox records by delivery state, giving its investigation view API a direct typed lookup for queued, acknowledged, retry, failed, and other persisted states.

The view reads the named `outbox` database, follows persisted state changes, and supports rebuilds from canonical records. Re-enqueuing identical evidence keeps the existing outbox identity rather than duplicating the view row.
