# PROLOG-RLM SUBAGENTS NOW HAVE AN ACTUAL LEASH

## Changes

The bounded `rlm_subagent` path now runs completion as child-owned supervised work. Results propagate back to the parent as typed closed data, cancellation stays cancellation, and mailbox backpressure is recorded instead of being misreported as delivery.

The follow-up closes the nastier possession gap: once a child is spawned, its normalized capability ceiling and narrowed authority context become authoritative for completion and tool calls. Registration-time options cannot quietly hand the child broader powers or fake another runtime identity.

Recursive subagent registration fails closed for now unless a future binding carries an explicit depth/concurrency identity contract. No accidental infinite delegation-by-vibes.

Exact merged verification reported 75 deterministic suites with 783/783 passing, runner integrity 19/19, deterministic benchmark 16/16, deep experiment 15/15, and all 3 Nix flake checks passing.
