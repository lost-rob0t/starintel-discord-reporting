# PROLOG-RLM STOPPED BEING A CHECKOUT-ONLY EXPERIMENT

## Changes

Prolog-RLM now ships as a flake-native SWI-Prolog runtime with pinned inputs, an installable package, a wrapper, and clean outside-checkout load checks. Downstream projects can consume it as an actual dependency instead of cloning the repo and hoping the environment lines up.

Short KB prompts can now compile deterministically into closed typed actions. The initial command path includes `delegate_subagent -> tool(rlm_subagent)` without turning KB data into arbitrary executable Prolog.

There is also a pure generic configuration-evolution kernel for closed candidates, deterministic mutation/crossover, lineage fingerprints, vector fitness, and Pareto selection. Product-specific genotype semantics stay downstream.

>prompt compiler got verbs
>evolution kernel stayed data
>less glue, more Prolog
