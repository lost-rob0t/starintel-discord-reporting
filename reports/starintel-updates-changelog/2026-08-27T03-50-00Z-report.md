## PROLOG-RLM CAN INSPECT SKILL RELATIONSHIPS AND MEASURE COMPILER SELECTION

## Changes

Prolog-RLM now exposes a deterministic, read-only graph over normalized skill metadata. `requires`, `suggests`, `conflicts`, and `supersedes` relationships can be inspected and validated without turning the graph into another selector or capability authority.

The existing prompt compiler also has a deterministic skill-selection evaluator now. It measures expected and forbidden selections, precision/recall, false positives/negatives, token cost, and per-dimension correctness against a closed corpus while still routing every case through the canonical compiler.
