## QUASAR NOW CATCHES MISSING NATIVE LIBRARIES BEFORE STARTUP FALLS OVER

## Changes

Quasar now preflights the native runtime before dev and production startup, covering SQLite, OpenSSL, rabbitmq-c, LMDB, and libffi. Missing libraries fail immediately instead of surfacing later as a foreign-library load crash.

The runtime contract is now checked across the Lisp system, Ubuntu packages, Nix libraries, launcher fallbacks, and CI gates. CI also boots a fresh Nix environment, loads the real `quasar-web` system, and starts the actual dev stack, so a dependency definition that only works on the prepared GitHub runner should get caught.
