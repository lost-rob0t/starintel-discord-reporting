# Tek9 becomes a consumable Nix package

## Changes

- Tek9 now exports a real Nix package for both `x86_64-linux` and `aarch64-linux` instead of being development-shell-only.
- Downstream flakes can load `:tek9` through an SBCL package closure with its Lisp dependencies and LMDB linked correctly, while mutable database state stays outside the Nix store.
- Exact-head validation passed on Ubuntu 22.04 and 24.04, including downstream package smoke, benchmark-regression, and merge-gate jobs.
