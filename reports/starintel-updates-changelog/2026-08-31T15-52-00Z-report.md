# Prolog-RLM tightens child capability and deadline handling

## Changes

- Child model sessions now receive the child capability set, not the parent session's broader context tools. A child with zero context budget no longer gets context schemas it cannot legally call.
- Completion wall-time limits now propagate through skill compilation instead of being wrapped as `skill_compilation_failed`. Deadline handling can report the real timeout again.
- The deadline regression was reproduced intermittently before the fix and ran 6/6 green in the paired post-fix check recorded with the landed change.
