# Zara keeps live latency traces out of checkpoint state

## Changes

Zara no longer stores the live latency trace object inside checkpointed agent graph state. The trace is extracted before graph execution and bound to the agent node instead, avoiding the msgpack serialization failure that was crashing voice-agent turns.

Direct node callers keep the existing state-dict fallback, so the fix removes the checkpoint failure without changing that call contract.
