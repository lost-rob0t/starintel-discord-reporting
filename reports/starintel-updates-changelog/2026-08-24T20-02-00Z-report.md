# STARINTEL SERVER JUST GOT REAL OAUTH

PR #118 landed.

StarIntel now ships a built-in OAuth 2 authorization-code provider with `/oauth/authorize` and `/oauth/token`, PKCE S256, exact redirect validation, scoped access, one-time codes, and bearer tokens.

The bigger architecture win: integrations don’t get to invent their own auth anymore.

Bixby support is now an optional Common Lisp ASDF add-on that plugs into the same core OAuth/authz system as everything else. The server also gained a reusable add-on lifecycle with clean start/stop handling and rollback-safe reloads.

Tests cover OAuth behavior, add-on loading, reloads, and client registration.
