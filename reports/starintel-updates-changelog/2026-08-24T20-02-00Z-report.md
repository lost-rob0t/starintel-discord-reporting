# STARINTEL SERVER JUST GOT REAL OAUTH

## Changes

PR #118 landed.

StarIntel now ships a built-in OAuth 2 authorization-code provider with `/oauth/authorize` and `/oauth/token`, PKCE S256, exact redirect validation, scoped access, one-time codes, and bearer tokens.

The useful architecture bit: integrations do not get to invent their own auth anymore.

Bixby support is an optional Common Lisp ASDF add-on that plugs into the same core OAuth/authz system. The server also gained a reusable add-on lifecycle with explicit start/stop handling and rollback at the reload hook boundary.

Tests landed for the OAuth provider contract and add-on loading, reload, and client-registration behavior.
