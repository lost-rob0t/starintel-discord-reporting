# Auto-Research retires duplicated StarIntel worker profiles

## Changes

- The old autonomous StarIntel ADARD, implementation, source-enrichment, contract-audit, verification, and generic Agent Zero worker profiles are retired after their work moved to Hackmode.
- Auto-Research no longer installs those retired profiles, and prompt tests now enforce Hackmode as the source-of-truth boundary instead of keeping two competing worker stacks alive.
