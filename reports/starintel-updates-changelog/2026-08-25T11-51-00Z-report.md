# Prolog-RLM can execute closed prompt commands through typed tools now

## Changes

- Compiled short-prompt commands can now cross the narrow bridge into the canonical typed tool runtime instead of stopping at inert command data.
- The bridge verifies the compiled command fingerprint before execution, then projects only the normalized arguments for the allow-listed tool target.
- Capability, authority, effects, cancellation, limits, and scheduling still stay in the existing tool runtime. A prompt command does not get to invent a second execution path.
