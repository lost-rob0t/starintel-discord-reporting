# Hackmode materializes operation asset views and hardens extension identity

## Changes

- Operation-local asset investigation queries can now use materialized views that are maintained on canonical writes and rebuilt for legacy operation data. Typed asset queries no longer need to scan the whole local store.

- Hackpert now snapshots expert-extension ID and version strings at construction and returns defensive identity copies, so caller-side string mutation cannot rewrite registered extension identity.
