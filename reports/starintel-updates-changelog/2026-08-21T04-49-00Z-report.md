# Auto-Dig can now mass-build DNC people accountability queues without faceplanting the site

## Changes

- Added a DNC key-people generator/workflow that materializes WEF-link and accountability queues across the current people set, instead of hand-building one packet at a time.
- Site builds now collapse identical duplicate packet records, preserve real conflicts under deterministic variant IDs, and index people relations so bulk datasets do not turn the directory into molasses.
- Validation/build paths were split so queue generation and people-directory checks can run without rebuilding the entire published site every time.
