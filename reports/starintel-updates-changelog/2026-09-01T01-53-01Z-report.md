# Hackpert freezes objective identity against caller mutation

## Changes

Hackpert objective IDs and versions are now copied at construction, and public accessors return defensive snapshots instead of exposing the stored identity strings directly.

The landed regression covers both sides of the boundary: mutating caller-owned strings after construction cannot rewrite the objective, and mutating values returned by the accessors cannot rewrite it either.
