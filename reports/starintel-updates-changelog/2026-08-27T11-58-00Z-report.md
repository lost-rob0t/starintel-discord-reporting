## PROLOG-RLM'S REAL CONSTRAINT BENCHMARK NOW RUNS THROUGH THE ACTUAL TYPED RUNTIME

## Changes

The constraint benchmark now uses a deterministic host-owned CSP fixture and verifier instead of treating planner output as the answer. The benchmark can exercise depth lanes while keeping the final assignment as data that the host independently checks.

The typed-plan contract now lives in the core RLM skills, not benchmark-only prompt glue. Benchmark guidance stays downstream-only, so the test is measuring the runtime contract instead of quietly teaching the benchmark how to speak it.

Planner context and task output are separated too. A valid planner object cannot leak through as the completion result; only the value materialized by the executed final step reaches the task verifier.
