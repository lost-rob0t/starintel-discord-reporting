# Auto-Dig hardens the live provider tool loop

## Changes

Auto-Dig now retries bounded transient provider failures instead of killing the run on the first rate-limit/server-side fault. Non-transient failures such as authorization errors still fail without retry.

Provider-native tool names are now projected through a reversible safe wire encoding, so dotted MCP names survive OpenAI-compatible function-name restrictions and round-trip back to their canonical runtime identity.

Read-only MCP handler failures can now return a bounded tool-error observation to the model for repair or fallback instead of terminating the whole direct session. Effectful tool failures remain fatal.
