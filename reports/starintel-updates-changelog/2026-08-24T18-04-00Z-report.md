# STARINTEL CAN NOW RUN FEDERATED-SOCIAL INGESTION AS A REPRODUCIBLE REMOTE ACTOR

## Changes

A StarIntel runtime now has a clean boundary for hosting non-Common-Lisp actors as independent services instead of smuggling them into the in-process actor system.

The first integration packages a federated-social monitoring actor reproducibly, exposes health/readiness checks, supports target discovery and probing, and includes deterministic plus live public-network smoke validation.

That gives StarIntel a repeatable pattern for adding external-language actors without weakening runtime ownership or turning deployment into a hand-built sidecar pile.
