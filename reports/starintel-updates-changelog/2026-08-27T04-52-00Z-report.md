## PROLOG-RLM RETRIES STRUCTURALLY BAD PLANS BEFORE EXECUTION

## Changes

Prolog-RLM now validates a parsed planner candidate before executing it. Structurally invalid typed plans can consume the configured planner retry budget instead of falling through into execution.

If retries run out, the failure is explicit and usage is still accounted. Capability denials and budget exhaustion stay policy outcomes rather than being treated as repairable planner syntax.
