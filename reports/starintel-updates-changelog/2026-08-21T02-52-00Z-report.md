# Auto-Dig just grew real procurement collectors

## Changes

- FBI TSC research now has a deterministic procurement scraper plus a scheduled collection workflow, instead of relying only on hand-curated packet work.
- Auto-Dig also added a USAspending award-transaction collector, historical TSC vendor lineage, and public TSC staffing-posting collection. The landed packet now links BAE and IntelliWare award history into the same research chain.
- Connector-only Auto-Dig runs can now use GitHub CI as the authoritative validation gate, which matters when the worker is operating through the GitHub connector instead of a local clone.
