# Prolog-RLM stops one bad native call from killing valid siblings

## Changes

- Native direct-mode preflight now classifies recoverable call faults per call instead of aborting the whole batch when one request is malformed.
- Malformed arguments and unavailable tool schemas come back as bounded repair observations, while duplicate IDs, unsafe effect batching, cancellation, and other batch-fatal invariants still fail closed before execution.
- Valid read-only sibling calls can keep running, and faulted calls are not executed or charged against tool/context budgets.

Landed change: <https://github.com/lost-rob0t/prolog-rlm/commit/6957c30c88f9548137a8ff9c3a0720f9bdadb210>
