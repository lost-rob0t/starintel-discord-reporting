# Prolog-RLM short commands can now pick a subagent role and skills

## Changes

- Compiled prompt commands can now carry a trusted subagent role and skill selection into the existing delegation path.
- That selection is bounded and fingerprinted with the compiled command. The child prompt compiler still decides whether a named skill is actually admitted.
- Role and skill metadata still grant no capability or authority, and conflicting delegation policy is rejected instead of silently merged.
