## 🌌 Quasar: large graphs now shed detail instead of tanking interaction

**Status:** `LANDED` • `main`

## Changes

- High-count graph rendering now uses runtime level-of-detail tiers instead of drawing the same amount of UI at every scale.
- WebGL rendering is selectable through the graph adapter while Canvas remains the safe default.
- Labels are suppressed during viewport motion to prioritize interaction latency, then restored when motion stops.
- Browser benchmarks now compare renderer behavior across graph sizes and report the active performance tier.
