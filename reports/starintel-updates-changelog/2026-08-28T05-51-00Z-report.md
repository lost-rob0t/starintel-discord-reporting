## STARINTEL GETS A GENERIC TARGET-CREATE API

## Changes

StarIntel core now exposes authenticated `POST /api/v1/targets` for generic target submission. The route requires `targets:dispatch`, validates the request at the HTTP boundary, and returns a narrow acceptance receipt instead of leaking backend internals.

Idempotency is principal-bound. Replaying the same request returns the existing target instead of dispatching another one, while reusing the same idempotency identity with changed target content is rejected.
