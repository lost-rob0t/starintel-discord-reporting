### 🎯 Next measurement: real coverage

The next active verification rollout is coverage instrumentation across the maintained project set.

The explicit target is **100% reachable branch coverage across maintained code**.

- Zara will measure line + branch coverage.
- prolog-rlm will use native Prolog coverage instrumentation and path/clause evidence appropriate to the runtime.
- Other projects get language-native coverage tooling.
- No guessed percentages will be published.
- Once every coverage gate has actually run, the next update will publish the measured percentages and remaining uncovered branches/paths.

```text
COMMITS  -> how quickly changes enter the tree
TESTS    -> how much explicit verification exists
COVERAGE -> what executable behavior those tests actually reach
```
