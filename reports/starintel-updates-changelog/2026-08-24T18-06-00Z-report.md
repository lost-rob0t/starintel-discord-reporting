# TEK9 NOW HAS REAL COMPOSABLE TRANSACTIONS AND GRAPH LIFECYCLE OPERATIONS

## Changes

Tek9 can now group document, index, graph, and view mutations inside one explicit LMDB transaction. Compatible nested calls reuse the active transaction, while invalid write-inside-read and cross-database nesting fail closed instead of pretending separate environments are atomic.

The graph API also gained first-class lifecycle operations for fetching edges, enumerating graph namespaces, deleting a node with all incident edges and adjacency records, and clearing one logical graph without touching neighboring graph namespaces.

That gives higher-level StarIntel code a proper atomic substrate for mixed graph/document work instead of stitching together individually committed storage calls.
