# STAR SERVER FINALLY GOT A REAL CLIENT CONTRACT

## Changes

- Star Server PR #104 landed a generated gserver client contract instead of letting client behavior keep drifting around hand-written request helpers.
- The client now has a shared transport/error boundary plus stable convenience calls for control-plane operations, while the older document/query helpers route through the same path.
- Local admin credentials are handled behind the client boundary, and secret-bearing result objects redact the API key when printed instead of spraying it into logs like an idiot.
- The merge also fixes response handling so malformed/truncated JSON is rejected instead of being treated as a valid server response.
