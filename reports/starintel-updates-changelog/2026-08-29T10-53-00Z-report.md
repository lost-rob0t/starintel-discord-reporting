# StarIntel Emacs client goes async

## Changes

- The Emacs client now runs against the public HTTP contract asynchronously, with capability discovery before interactive commands and explicit request deadlines.
- Bearer auth stays in headers, correlation IDs are carried through requests, and client errors are typed without leaking the configured token.
- Versioned API routes are preferred. Legacy routes are only used when the server advertises them through compatibility capabilities.
- The landed client includes a hermetic fake-transport ERT suite. The merged PR records 42 tests passed with 0 unexpected results.
