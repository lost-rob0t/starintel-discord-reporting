# Auto-Research pins StarIntel's embeddable library boundary

## Changes

Auto-Research landed the research and design packet for turning the existing StarIntel runtime into an explicit embeddable Common Lisp application boundary without creating a second lifecycle owner.

The design keeps `star.runtime` as lifecycle authority, reuses the existing typed service-call context, and moves application operations toward explicit runtime + context + typed request + typed-port contracts. The first required proof is fake-backed runtime isolation, not a claim that two full live production runtimes already work in one Lisp image.

This is **design-ready for operator review only**. Architecture approval and implementation authorization are still pending, and every proposed implementation slice remains gated on explicit operator approval.
