## Zara: local AI, Prolog Studio, and direct APK downloads

## Changes
- Android now hosts compatible LiteRT-LM models in an embedded service, with verified installs and model switching. Local chat stays Prolog-first; unmatched text can use the selected local model. Offline Android speech is a separate provider.
- Prolog Studio adds semantic highlighting, completion support, undo/redo, fact/rule graphs, a query console, and private-workspace import/export.
- Phone and Wear APKs now have a rolling `android-latest` channel published after green master CI. This is a prerelease channel, not a fixed version: use the manifest to identify the build.
