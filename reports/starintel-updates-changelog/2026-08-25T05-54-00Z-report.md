# Prolog-RLM STOPS SHOWING THE MODEL TOOLS IT CANNOT USE

## Changes

- Planner-facing tool schemas now obey the same capability boundary as executable runtime tools. A denied tool no longer gets advertised to the model just to fail later at execution.

- This also cuts useless planner context: tool names and descriptions outside the active capability set stay out of the request entirely.

- The landed regression checks that an allowed tool remains visible while a denied tool's name and description are absent. Focused completion/runtime checks passed before merge.
