# Prolog-RLM now keeps subagent delegation provenance without turning it into authority

## Changes

- Host-selected subagent role and explicit skill metadata now survive into the supervised child/result path as trusted delegation provenance.
- That metadata stays inert. It does not widen capabilities, tool authority, or completion budgets.
- Invalid delegation options now fail with grounded errors while preserving the existing subagent result ABI instead of leaking caller-controlled terms into failure payloads.
