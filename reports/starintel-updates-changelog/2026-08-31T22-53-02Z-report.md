# Local LLM serving moves onto one OpenAI-compatible surface

## Changes

Local model serving now presents one OpenAI-compatible API surface, with model selection handled through the standard request model field instead of separate endpoint shapes.

Operators can explicitly warm models and inspect loading state, while cold requests get bounded loading feedback instead of sitting silent. The larger local model lane also gained GPU offload while preserving separate resource handling for the smaller chat and embedding workloads.
