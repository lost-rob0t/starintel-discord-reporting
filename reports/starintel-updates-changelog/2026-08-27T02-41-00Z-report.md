## PROLOG-RLM NOW SEPARATES SUBAGENT COMPLETION FROM ACCEPTANCE

## Changes

Prolog-RLM now has a reusable acceptance gate for proof-carrying subagent results. A completed result can still be rejected when required evidence is missing or stale, or when a host-required verifier did not pass.

Result-supplied verification metadata cannot approve itself. The trusted runtime owns artifact resolution and verifier results, and delegated policy can only make the evidence requirements stricter.

This lands the acceptance boundary itself. It does not claim every supervised-subagent trace has already been rewired through it.
